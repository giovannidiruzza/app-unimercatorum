# Interfaccia Flottante Iniettata e Struttura File Flat

L'estensione inietterà un **Pannello di Controllo Flottante** direttamente all'interno della pagina dell'insegnamento per garantire visibilità costante dello stato del download senza rischio di chiusura accidentale del popup. I file scaricati verranno salvati in una **struttura flat** (tutti i file salvati nella cartella radice scelta dall'utente), nominati secondo lo schema convenzionale `Cap. XX - Lez. YY - Titolo.pdf` per garantire ordinamento alfabetico immediato e portabilità senza nidificazione di cartelle.
