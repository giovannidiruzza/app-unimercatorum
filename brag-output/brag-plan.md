# Brag Plan: Multiversity Suite

## What is this app?
Multiversity Suite è un'estensione browser premium che automatizza lo studio universitario su tutte le piattaforme del gruppo Multiversity (Mercatorum, Pegaso, San Raffaele), unificando il download in batch delle dispense PDF e l'auto-player sequenziale intelligente certificato al 100%.

## The angle
Basta perdere ore a cliccare manualmente "Prossimo video" o scaricare centinaia di slide una alla volta. Multiversity Suite trasforma la piattaforma e-learning in un flusso continuo, fluido e completamente autonomo.

## Hook (first 2-3 seconds)
"Ore perse a cliccare 'Prossimo video' sulle piattaforme universitarie?"
Compare a schermo una clessidra stilizzata con il logo Multiversity e una barra di avanzamento che schizza istantaneamente al 100%.

## Key moments (the middle)
- **Auto-Play Sequenziale 100%**: transizione automatica tra lezioni, capitoli e macro-sezioni a fisarmonica, con stealth playback rate e anti-disconnessione.
- **Batch Dispense PDF Downloader**: estrazione diretta con File System Access API in locale, zero server esterni, sovrascrittura pulita e ordinata.
- **Night Mode con Screen Wake Lock**: attiva l'estensione, spegni le luci e lascia completare la riproduzione notturna senza sospensione del PC.

## Outro / punchline
"Lo studio online, finalmente col pilota automatico. Multiversity Suite."

## User flow worth showing
1. Clic sul badge flottante `🎓 Multiversity Suite` direttamente nella videolezione.
2. Attivazione dell'interruttore `🎬 Avvia Riproduzione` con auto-avanzamento 100% e Night Mode attiva.
3. Le lezioni e i capitoli scorrono in sequenza certificata mentre le dispense vengono archiviate sul PC.
